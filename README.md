# 音乐

把当前账号自己的音频整理成曲库，并在页面里播放。版本 **0.5.5**。

播放列表里始终有一份「全部歌曲」。还没有选择专辑、自建列表或手动调整过队列时，待播内容就是资料库中的全部歌曲。

## 功能

- 资料库：主页、最近添加、艺人、专辑、歌曲、喜爱的歌曲
- 播放列表：内置「全部歌曲」，以及自行新建、重命名、排序、删除的列表
- 播放：播放 / 暂停、上一首、下一首、进度、音量、静音、随机、循环（关闭 / 全部 / 单曲）
- 待播清单：历史、正在播放、继续播放；可拖动排序，可移除，可清空
- 小窗：离开音乐页后继续播放。默认只显示封面和曲名；鼠标移入后出现关闭、打开、更多、歌词、列表和音量
- 沉浸播放：大封面或视频画面、歌词、待播清单、右上角音量和铺满屏幕
- 歌词：同目录歌词文件、音频内嵌歌词；可选在线歌词。支持逐行与逐词高亮，可微调时间偏移，也可自行导入
- 封面：内嵌图片、同目录封面图，都没有时按专辑生成纹样封面
- 从文件管理用「音乐」打开文件时，从这首歌开始，后面仍按全部歌曲继续

在线歌词默认关闭。每一首的播放地址、封面和歌词都会先检查当前账号是否可以读取该文件。曲库、播放列表和播放进度按账号分开保存。

## 安装

1. 将本目录作为 `music` 插件放到站点的 `plugins/music`。
2. 在插件管理中启用「音乐」。
3. 强制刷新页面（Ctrl+F5），左侧会出现「音乐」。

启用后会创建三张数据表：`plugin_music_track`、`plugin_music_list`、`plugin_music_list_item`。已启用过的站点会自动补上缺失的表和 `lyricOffset`、`favorite` 字段。

卸载只停止定时扫描，不删除数据表，也不删除原来的音频、封面或歌词文件。若要清空曲库记录，需要自行处理这三张表。

## 使用

### 建立资料库

把音频放到自己的文件夹，打开音乐页，点击左下角「扫描资料库」。别人分享的文件不会入库。

每次扫描只读取自己名下新的或修改过的文件，数量不超过配置中的「每批扫描数」。这一批满了会提示再扫一次。文件已经删除的条目会从曲库和播放列表里去掉，源文件和「音乐资料」保留。启用后，定时任务也按同一规则扫描，每个文件仍归它的拥有者。

扫描会读取标签（标题、艺人、专辑、音轨号、年份、时长、封面、内嵌歌词）。视频入库时只读取时长，标题来自文件名。

视频默认不扫描。需要时在插件配置里打开「扫描视频」，保存后再扫描。关闭该开关不会移除已经入库的视频。已经入库、时长仍为 0 的视频，要等文件有修改后才会重新读取时长。

修改过扩展名列表后要先保存配置，再重新扫描。

### 浏览和播放

- 双击歌曲，或点专辑封面上的播放键，从该位置开始播放。
- 在「歌曲」或「全部歌曲」里点「播放」，按当前顺序播放全部；点「随机播放」则打乱顺序。
- 歌曲「更多」菜单可以「下一首播放」或「稍后播放」，也可以加入某个自建播放列表。
- 空格播放或暂停。左右方向键快进或快退 5 秒，按住 Ctrl 或 Command 则切歌。Ctrl 或 Command 加上下方向键调节音量。Ctrl 或 Command 加 F 聚焦搜索。

在专辑、艺人或自建列表里播放时，队列就是这一组歌曲。在「歌曲」或「全部歌曲」里播放时，队列就是全部歌曲。

### 播放列表

侧栏「播放列表」下第一项永远是「全部歌曲」，内容与资料库同步，不能重命名、不能删除。在自建列表里按住 Ctrl 或 Command 点选后，选择条是「从播放列表移除」，可以一次移出多首，只改这个列表。

在资料库页面，同一选择条是「从资料库移除」。歌曲菜单里也可以移除当前这一首；「歌曲」页在资料库里有视频时可以「移除视频」。这些操作只删除曲库记录和播放列表中的对应项，不删除原来的文件，也不删除「音乐资料」里的歌词和封面。

自建列表可以在侧栏的加号、列表页的「新建播放列表」，或歌曲菜单的「添加到播放列表」里创建。在列表内拖动行可以调整顺序。

### 还没指定队列时

如果当前没有正在使用的队列，打开音乐页后会把全部歌曲放进待播清单，但不会自动出声。此时点播放，从第一首开始。

已经有上次的播放队列，或手动改过待播清单时，不会用全部歌曲覆盖。从文件管理打开一首歌时，会从这首歌起播，并把它放进全部歌曲的顺序里；资料库中还没有这首歌时，它排在最前，后面仍是全部歌曲。

### 小窗

音乐页不可见且有正在播放的曲目时，小窗出现在页面上，可以拖动，位置会记住。

- 默认第一行是封面、标题和艺人，下面是进度和播放控制。
- 鼠标移入后，第一行改为关闭、打开音乐，以及更多、歌词、待播清单和音量。
- 「更多」里可以加入播放列表、查看简介、标记喜爱、回到当前歌曲、打开专辑或艺人、复制信息、在文件管理中定位，以及开关大图、待播清单和歌词。

点「关闭小窗」只隐藏这一轮播放的小窗，不停止播放。

### 歌词

查找顺序：

1. 与音频同一目录、主文件名相同或与标题匹配的歌词文件（lrc、txt、srt、vtt、ass、ssa、ttml、xml、json、yrc、lrcx）
2. 音频标签里的歌词
3. 仅当插件配置打开了「在线歌词」时，按勾选的来源在线查询

在线来源按下面的顺序尝试。先找到逐字歌词就直接使用；都没有逐字歌词时，才用第一份逐行歌词。

| 来源 | 时间精度 | 说明 |
| --- | --- | --- |
| [AMLL TTML DB](https://github.com/amll-dev/amll-ttml-db) | 逐字 | 社区维护的 TTML 歌词库，收录以中文、日文歌为主。每天从 GitHub 下载一次索引（约 1.6 MB），按歌名和艺人匹配，再用 TTML 里的时长核对 |
| 酷狗音乐 | 逐字 | 查询 `lyrics.kugou.com`，取 KRC 歌词并在服务器上解密 |
| lrclib.net | 逐行 | 开放歌词库 |

只按歌名查询时，必须能核对时长（相差 4 秒以内）。知道艺人时，艺人也要对得上。歌名里带有 DJ、Remix、Live、伴奏、翻唱等字样的版本会被排除，除非你的曲名里也带了。

已经存过、并且时长覆盖整首歌的歌词不会自动重新查询。正在播放时，「更多」→「歌词」里可以：

- 「重新获取歌词」：忽略已保存的结果再查一遍。新结果只写入插件缓存；「音乐资料/歌词」里的文件不会被覆盖。如果之后那个文件的修改时间更新，仍以文件为准。
- 「在线查找逐字歌词」：只在还不是逐字歌词时可用，找到后替换缓存和存档。

只有行时间的歌词（普通 LRC、SRT、lrclib）按整行高亮。带逐字时间的歌词（逐字 LRC、网易云 YRC、酷狗 KRC 文本、TTML、ASS 的 `\k`、JSON）才逐字扫色；格式里带了每个字的结束时间时，拖长音和字间停顿按实际时长显示。TTML 中的翻译、罗马音和背景和声不计入主歌词。

查询结果和导入的歌词会记在该文件旁，供下次使用。歌词菜单里可以提前或延后 0.5 秒，或把偏移重置为 0。导入文件上限 500 KB。

### 封面

依次使用：「音乐资料/封面」里已有的图片、音频内嵌图片、同一目录下名为 cover、folder、album、front、artwork、albumart、folder-large 的 jpg / jpeg / png / webp / bmp。都没有时生成一块带专辑名的纹样图。查看封面只写入插件临时缓存，不会往「音乐资料」里新增文件。

## 配置

| 项 | 说明 |
| --- | --- |
| 使用权限 | 哪些账号可以使用这个插件 |
| 添加到菜单 | 是否在左侧菜单显示 |
| 子菜单 | 是否作为子菜单项 |
| 扫描视频 | 默认关闭。打开后把 webm、mp4、m4v、mov、mkv、avi 纳入扫描 |
| 在线歌词 | 默认关闭。打开后才在没有本地歌词时在线查询 |
| 在线歌词来源 | 打开在线歌词后出现。可勾选 AMLL TTML DB、酷狗音乐、lrclib.net，默认全选。查询时会把歌名、艺人和时长发给所选服务 |
| 每批扫描数 | 每次读取标签的文件数，建议 20–200 |
| 扩展名 | 默认 `mp3,flac,m4a,aac,ogg,oga,opus,wav,wma` |

## 权限与数据

- 未登录不能使用曲库、播放和播放列表接口。
- 播放、封面、歌词都会确认当前账号可以读取对应文件。
- 会修改数据的请求使用 POST，并校验与登录 Cookie 一致的 CSRF 令牌。
- 播放进度、音量、循环、随机和小窗位置保存在本机浏览器，键名带有账号编号。
- 喜爱标记和播放列表保存在数据库里，只属于当前账号。
- 封面和歌词缓存写在插件数据目录中，不回写到原始音频里。查看封面不会往「音乐资料/封面」新增文件。

## 限制

- 开始播放之后，本机会话最多记住 500 条队列。未开播的「全部歌曲」不写入这 500 条，下次打开仍按当时的资料库重新生成。
- 随机开启后，顺序只在本次播放中有效。
- 在线歌词依赖服务器能访问外网。AMLL TTML DB 需要能访问 `raw.githubusercontent.com`，第一次查询要先下载索引，会慢几秒。
- 酷狗接口不是公开文档化的 API，随时可能变化；失效时会跳过，继续查询下一个来源。
- 加密的 `.krc` 文件不能从歌词菜单导入，只支持已解密的 KRC 文本。
- 视频在音乐页内播放；离开该页时画面不再显示，声音是否继续取决于浏览器对后台视频的策略。
- 曲库只包含自己拥有的文件，不包含别人分享的文件。不在扩展名列表里的格式也不会入库。
- 播放遇到网络中断，或缓冲超过 12 秒没有前进，同一首最多自动重试 2 次，然后停在当前歌曲。解码失败不自动重试。再按播放会重新尝试。
